Architecture · Current system

Jcode is one shared authority with many surfaces.

Clients converge on a versioned local protocol. The daemon owns session order, agent execution, durable state, background work, and reload continuity.

Authoritative path

One daemon decides order.

Clients never become transcript authorities. Session mutation, tool execution, durable commit, fanout, and reconnect replay remain daemon-owned.

Lifecycle paths

Async work returns to state.

Background tasks, swarm coordination, telemetry, and self-development reloads use dashed paths because they are scheduled or lifecycle work.

Fidelity ledger

25 source nodes → 11 concepts.

Client surfaces, provider/tool adapters, local stores, and build/version storage were collapsed. No source capability was invented.
